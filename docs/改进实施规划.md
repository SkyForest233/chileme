# Chileme UI 改进实施规划 — 分阶段最大化 AI 智能区间

> 目标：把之前 `Chileme_vs_KernelSU` 的 10 项改进，拆成 6 个独立可交付的 Phase，每个 Phase 控制在 **3-5 个文件、300-800 行改动、单一职责**，避免长任务导致 AI 上下文衰减。
> 原则：先地基后视觉，先无依赖后有依赖，每个 Phase 都能独立编译、独立测试、独立回滚。

---

## 为什么要分段？（AI 最佳智能区间研究）

- **上下文窗口**：超过 10 个文件 / 1500 行 diff，模型开始遗忘早期文件，出现“改 A 忘 B”。
- **单一职责**：KernelSU 的双主题分发就是文件级分叉，Chileme 也应一次只动一个子系统。
- **可验证**：每个 Phase 结束都有明确的 UI 可见变化 + 单元测试通过，方便人肉 QA。
- **可回滚**：每个 Phase 一个 commit，出问题只回滚一个 Phase。

## Phase 0 — 地基：主题引擎 7 档化（P0，预估 2h）

**范围**
- 新建 `ui/theme/ColorMode.kt`：照搬 KernelSU 的 7 档枚举 + `isSystem/isDark/isAmoled/isMonet/toNonMonet/toMonet`
- 扩展 `DataStore`：`paletteStyle: String, colorSpec: String, amoled: Boolean, enableBlur: Boolean, floatingBlur: Boolean, enableBadge: Boolean`
- 重构 `AgonAppTheme` / `MiuixRootTheme`：参数改为 `AppSettings(colorMode, paletteStyle, colorSpec, amoled)`，内部走 `rememberDynamicColorScheme(seed, isDark, isAmoled, paletteStyle, colorSpec)` + `animateColorScheme`
- `MainActivity` 的 `darkTheme Boolean` 改为 `colorMode: ColorMode`，`LocalColorMode` + `LocalEnableBlur` 下发
- 设置页增加 3 个 Switch：AMOLED 纯黑、启用模糊、启用角标（默认开，低端机可关）

**不做**：不碰底栏、不碰搜索、不碰液态玻璃，只改颜色生成。

**验收**
- 编译通过，`./gradlew testDebugUnitTest`
- 设置里切换 SYSTEM/LIGHT/DARK/AMOLED，颜色实时 `tween(450ms)` 过渡，无闪屏
- 深色模式下 AMOLED 时 `surface` 为纯黑 `#000000`
- 截图对比：旧版 vs 新版 7 档

**文件清单**
- `ui/theme/ColorMode.kt` (新增 ~80行)
- `ui/theme/Theme.kt` (改 ~60行)
- `ui/theme/MiuixRootTheme.kt` (改 ~50行)
- `data/FoodRepository.kt` / `AppViewModel.kt` (DataStore 读写 +30行)
- `ui/screens/SettingsScreen.kt` / `MiuixSettingsScreen.kt` (各 +40行)

**风险**：低，纯颜色层。

## Phase 1 — 动效地基：回弹、触感、Pager 弹簧、Scaffold 统一（P0，预估 2h）

**范围**
- 拷贝 KernelSU `PagerNavigationSpringSpec.kt` + `MainPagerState.kt`（`springAnimateToPage` + `isNavigating` + `navJob.cancel()`），替换 Chileme `MainActivity` 的 `animateScrollToPage`

- 卡片按压有下沉/倾斜反馈

**文件清单**

## Phase 3 — 底栏：液态玻璃 + Badge（P1，视觉最大提升，预估 3h）

**范围**

## 执行顺序与依赖图

```
Phase0(主题) → Phase1(动效) → Phase2(搜索) → Phase3(底栏) → Phase4(Home) → Phase5(自适应+设置) → Phase6(Polish)
     ↓              ↓
   无依赖         依赖 Phase0 的 LocalEnableBlur
```

- Phase0 必须最先，否则后续 blur 开关无意义
- Phase1 无依赖，可与 Phase0 并行（不同分支）
- Phase2 依赖 Phase0 的 `LocalEnableBlur`（TopAppBar 透明）
- Phase3 依赖 Phase0+Phase1（blur + Pager弹簧）
- Phase4 依赖 Phase0（WarningCard 颜色）
- Phase5 依赖 Phase0+Phase1
- Phase6 最后

## 每个 Phase 的 AI 任务模板（复制即用）

```
目标：完成 Phase X 的 Y
输入：docs/Chileme_vs_KernelSU_改进建议.md + 本规划
输出：3-5 个文件改动，单 commit，附截图/录屏描述

验证：./gradlew assembleDebug + testDebugUnitTest + 手动切换深浅/Miuix/Material
```
