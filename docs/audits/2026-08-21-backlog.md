### 1.2 `UnusedAttribute` ×2 —— ❌ 误报，不要删

```
AndroidManifest.xml:16  enableOnBackInvokedCallback（application）
AndroidManifest.xml:22  enableOnBackInvokedCallback（activity）
```

lint 说"只在 API 33+ 生效，当前 minSdk 26"。这是**预期行为**：
低版本忽略该属性，高版本启用预测性返回。而本项目预测性返回是核心体验
（`NavTransitions.MiuixDefault` 全宽跟手滑出 + 下层视差，
`MainActivity.kt:396`），**删掉会破坏 Android 13+ 的返回手势**。

→ 保持现状。如需消音，在 `<application>` 加
`tools:targetApi="tiramisu"`（需引 `xmlns:tools`）。

### 1.3 `OldTargetApi` ×1 —— 🟡 需你决策

`targetSdk = 36`，而 `compileSdk = 37`（为满足 Miuix 要求而升）。

升 `targetSdk` **不是改个数字**，会触发新一档行为变更（后台限制、
权限模型、边到边强制等），必须实机回归。且 Google Play 的合规截止日期
才是真正驱动力，本项目未上架 Play，优先级不高。

→ **建议暂不升**，等有完整回归条件时单独做。

### 1.4 `IconLauncherShape` ×5 —— ❌ 误报

5 个密度桶的 `mipmap-*/ic_launcher.png` 被判"图标不该是特定形状"。
项目已正确提供 `mipmap-anydpi-v26/ic_launcher.xml` 自适应图标
（background + foreground + **monochrome**，themed icon 都做了）。
那 5 个 PNG 只是 API 26 以下的回退——而 minSdk 现在已是 26，
理论上**这 5 个 PNG 已无设备会用到**。

→ 可选清理：删掉 5 个 PNG 能减小包体。但需先确认没有别处引用
`@mipmap/ic_launcher` 的非自适应场景（如通知小图标）。属锦上添花。
