## Warnings（4-6 分项）

### Accessibility — 4/10
1. **CheckSwitch 缺少开关语义**（`ui/components/Common.kt:~450`）：自定义开关使用裸 `clickable`，无 `Role.Switch` / `toggleable()` / `stateDescription`。TalkBack 会将其读作普通按钮，且不播报开/关状态。修复：`Modifier.toggleable(value=checked, role=Role.Switch, onValueChange=...)`。
2. **触摸目标低于 48dp**：`QuantityStepper` 的 +/- IconButton 为 32dp（Common.kt:214,228）、设置页阈值步进器为 30dp（SettingsScreen.kt:271,284）、悬浮导航槽位高 44dp。MD3/WCAG 要求最小 48dp。修复：保持视觉尺寸不变，用 `Modifier.minimumInteractiveComponentSize()` 或增加外部 padding 扩大命中区。
3. **全项目 0 处 `Modifier.semantics`**：图表（柱状图/环形图）纯视觉呈现，屏幕阅读器无法获取数据。修复：为图表容器添加 `contentDescription` 汇总数值。

### Layout — 4/10
4. **无窗口尺寸类支持**：未使用 `calculateWindowSizeClass` / adaptive API，所有屏幕为单栏手机布局。需求文档声明"支持不同屏幕尺寸和折叠屏"，但展开态折叠屏/平板（≥600dp）不会切换为 list-detail 或多列网格。修复：引入 `material3-window-size-class` 或 `material3-adaptive`，食品列表在 Medium+ 使用双栏 list-detail。
5. **页面边距 20dp 非 spacing token 体系**：MD3 建议 compact 16dp / medium+ 24dp，且推荐集中定义 spacing 常量对象。当前 20dp 字面量散布全部屏幕文件。

### Navigation — 5/10
6. **未选中导航项无标签**：FloatingPillNav 未选中 Tab 仅显示图标。MD3 导航规范明确"Always show labels (don't use icon-only)"。同时自定义实现缺少 `NavigationBar` 内建的 selected/tab 语义。
7. **无自适应导航变换**：MD3 要求 compact→bottom bar、medium→rail、expanded→drawer。当前所有尺寸均为底部胶囊导航（与问题 4 同源）。

### Shape — 5/10
8. **`MaterialTheme.shapes` 使用次数为 0**：67 处内联 `RoundedCornerShape` 字面量（50/24dp/20dp/16dp…）。虽在 DESIGN_SPEC 中有文档化且全局一致，但未走 token：卡片 24dp 偏离 MD3 medium(12dp)，Chip 全圆偏离 small(8dp)。修复（不改视觉）：把项目自定义半径注册进 `MaterialTheme(shapes = Shapes(medium=24.dp,...))`，屏幕代码引用 `MaterialTheme.shapes.*`，一处可调。

## Passing（7-10 分项）

- **Theming 9/10**：种子色 → MaterialKolor 生成完整 ColorScheme，为 MD3 标准做法；动态取色按 API 31+ 正确门控且用户可开关；深色三档；主题持久化；预览用同一生成器保证所见即所得。扣 1 分：未提供 medium/high 对比度档位。
- **Typography 9/10**：80 处全部走 `MaterialTheme.typography` 语义角色，角色选择符合规范（卡片标题 titleMedium、按钮 labelLarge、辅助文本 bodySmall+onSurfaceVariant）。硬编码 fontSize 仅用于 emoji 装饰元素，可接受。
- **Color tokens 8/10**：0 处 material2 导入；0 处 Color.White/Black；屏幕代码除图表调色板（已在 DESIGN_SPEC 登记为例外）外无裸 hex；状态语义色独立于动态取色（符合 error 类角色"static"精神）。扣分：`ui.content`（状态内容色）直接用于 `surfaceContainer` 背景上的文本（HomeScreen UrgentRow 等），属跨对配对，深色模式对比度依赖人工色值而非配对保证；图表色不随主题种子变化，切"蜜桃/香芋"主题后统计页仍是绿色系。
- **Elevation 8/10**：正确采用 tonal-first——卡片用 surfaceContainer 分层、elevation ≤1dp；悬浮导航 6dp 阴影符合"浮于内容之上的元素可用阴影"例外。LargeTopAppBar 滚动态切换 scrolledContainerColor 正确。
- **Components 7/10**：Scaffold/Card/FilterChip/AssistChip/DatePickerDialog/AlertDialog/SwipeToDismissBox/SnackbarHost/SegmentedButton/LargeTopAppBar 等 material3 组件使用正确、变体得当。扣分：CheckSwitch 替代 Switch（用户明确要求的设计，但需补语义，见问题 1）；导航为自定义实现（见问题 6）。
- **Motion 7/10**：动画丰富且克制（56 处），导航指示器用 spring 物理符合 Expressive 方向；页面转场 280ms 接近 Medium2(300ms)。扣分：全部使用默认线性缓动的 `tween`，未采用 MD3 emphasized/standard 缓动曲线（`CubicBezierEasing(0.2f,0f,0f,1f)` 等），未使用 `MotionScheme`。

## Recommended Fixes (Priority Order)

1. **CheckSwitch 加 `toggleable(role=Role.Switch)` 语义** — 无障碍硬伤，5 行改动，零视觉影响
2. **小按钮触摸目标扩到 48dp**（minimumInteractiveComponentSize）— 无障碍硬伤，零视觉影响
3. **悬浮导航未选中项显示 labelSmall 小字标签** — 符合"always show labels"，改动小
4. **引入 window size class：列表页 Medium+ 双栏 list-detail、统计页多列** — 兑现"折叠屏适配"需求，改动最大但价值最高
5. **自定义半径注册进 MaterialTheme.shapes** — 架构改进，零视觉影响
6. **图表调色板改为从当前 colorScheme.primary 派生色阶** — 让统计页跟随主题种子色
7. **页面转场缓动换成 MD3 emphasized 曲线** — 锦上添花
8. **（可选）提供高对比度主题档位** — MaterialKolor 支持 contrastLevel 参数，成本低
