## 1. 产品定位

家庭场景的零食/食品库存管理 App：记录食品信息，自动计算过期日期，临期提醒，减少浪费。本地单机、无后端。

| 编号 | 功能 | 要点 |

## 4. 明确不做（需求边界，用户已确认）

- ❌ 推送通知 / 后台提醒（WorkManager）—— 临期提示只存在于应用内（首页提醒/状态色/到期日历），**没有系统通知**
- ❌ 补货/购物清单
- ❌ 桌面小组件（Widget）
- ❌ 条形码扫描、外部商品库 API
- ❌ 多人协作 / **自建**云同步服务 / 任何自有后端（无账号体系、无服务端）
  - **例外（用户已确认，见 F20）**：坚果云 WebDAV 备份是**用户自有网盘**的通道，凭据由用户自己填写、加密存本机，项目不提供任何服务端
- ❌ OCR 日期识别（v2.3 起下线，用户确认“识别率低、鸡肋”；不得重新引入 ML Kit）

如需新增以上功能，必须先与用户确认并更新本文档。

## 5. 验收标准

1. `./gradlew assembleDebug` 构建成功，无编译错误
2. 每个功能点可完整走通：添加 → 列表/首页展示 → 编辑 → 消耗 → 归档 → 恢复
3. 数据重启 App 后不丢失（DataStore 持久化）
4. 深色/浅色/动态取色下 UI 均可读，状态色对比度足够
5. 空态、错误态（如导入格式错误）有友好提示
