# 到期进度 → 整卡水波纹（MD3 Demo）

单文件网页 Demo（`index.html`，无构建、无依赖），用来预览一个改动想法：
**把食品列表卡片里的「到期时间进度条」换成整张卡片的水波纹进度**。

- 水波波面位置 = 保质期已过去的比例（正相关，与 `FoodCard.kt` 现在的进度条同源：
  `elapsedRatioAt()`）。
- 三态（安全 / 临期 / 已过期）配色取自 `ui/theme/Color.kt` 的语义色，深浅模式各一套。
- 顶部可切换：显示方式（原版 / 新方案 / 并排对比）、卡片底色（状态色容器 / 卡片原底色）、
  主题（浅色 / 深色），并可拖时间轴看水位推进与状态切换。

## 打开方式

直接双击 `index.html` 即可（纯静态）。若要走本地服务器：

```bash
python3 -m http.server 8080 --directory demo/expiry-wave
# 浏览器打开 http://localhost:8080
```

> 说明：本目录只是观感预览，**不参与 App 构建**，`app/` 下的 Compose 代码未做任何改动。
