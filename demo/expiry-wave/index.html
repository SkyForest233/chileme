食品列表 · 到期进度改造预览

MATERIAL 3 · DEMO

把「到期时间进度条」换成整张食品卡片的水波纹进度：水波推进的位置 = 保质期已过去的比例 （正相关，与现在 FoodCard.kt 里 elapsedRatioAt() 驱动进度条完全一致）。 点卡片可看水波上的按压涟漪，拖时间轴可看水位上涨与状态变色。

「原版」= 现在 App 里的卡片内线性进度条
状态色容器 = 直接把原来的进度条底色铺满整卡；卡片原底色 = 卡片外观不变，只叠一层水波
深浅两套都用 Color.kt 的状态语义色
拖动可看水位推进、剩余天数与三态（安全 → 临期 → 已过期）的切换；卡片颜色按 450ms 渐变过渡

这版 Demo 说明

  • 数据用真应用的算法：elapsedRatio = 1 - clamp(剩余天数 / 保质期, 0, 1)；文案「已过期 N 天 / 今天到期 / 还剩 N 天」；三态按分类阈值判定。卡片字段（生产日、到期日、分类、存放位置、库存数量）与 FoodCard.kt 一致。
  • 水波由 Canvas 2D 逐帧绘制：竖直波面 + 随波面推进的回声涟漪 + 波面描边与发光 + 前缘水光；波面位置线性映射到进度，所以「水位」就是进度本身（不是拿循环动画冒充）。
  • 填充沿用 App 的动效规范：400ms + MotionEasing.Standard（cubic-bezier .2,0,0,1）；按压涟漪沿用 M3 ripple；prefers-reduced-motion 下停止水波摆动，只留静态水位。
  • 「波幅 / 波速」滑杆只为方便你调观感；「重播填充」可重看一次水位上涨。
  • 真要落地的话，改动点在 ui/components/FoodCard.kt：把两处进度条行撤掉，在卡片背景层加一个 Canvas（或 drawWithContent + 波浪 path），进度源仍是 animateFloatAsState(item.elapsedRatioAt(LocalToday.current))，配色走 rememberStatusUi(status) 的 container/content。要注意卡片内容需要描边或提亮以保证文字对比度（尤其整卡状态底色 + 水体同色系时）。
  • 这是观感预览，仓库里没有改动 app/ 下的任何 Compose 代码。
